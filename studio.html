Connect to GitHub

Publishing saves projects straight to the website’s GitHub repository. You only need to do this once on each device.

How to get an access token
  1. Open GitHub → New fine-grained token.
  2. Name it “Portfolio Studio” and pick an expiry date.
  3. Under Repository access choose Only select repositories and pick your portfolio repository.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Generate the token and paste it below. It stays on this device and is only sent to GitHub.
